# Basic Excel Sales Analysis

## Project Overview
This project demonstrates the use of Microsoft Excel for organizing, cleaning, and analyzing sales data.

## Tools Used
- Microsoft Excel / Google Sheets

## Concepts Implemented
- Basic Excel formulas and functions
- IF function for sales classification
- Sorting and filtering
- Conditional formatting
- Duplicate value identification
- Data visualization using charts
- Data analysis using a sales dataset

## Objective
To develop practical spreadsheet skills and extract useful insights from sales data.

## Key Learning
Improved understanding of spreadsheet formulas, data cleaning, conditional formatting, and sales data analysis.
